# Numbers, frozen (S9, 2026-10-23)

Every number in the [README](../README.md), the [storyboard](storyboard.md), the [video](../video/script.md) and the
replay site (`npx ac site`), each with the primary source it was checked against and how. This list is what
"numbers frozen" means: a number that isn't here, or that disagrees with its source, doesn't go into the video or the
submission. Tag `freeze-numbers` marks the commit it describes.

How the list was made (S9):
- **Extract and recompute.** 10 agents, one per chunk (the README in five, the storyboard in two, the site's landing,
  verify and bench pages with their copy in `src/site/`, the A/B page, the two run reports), listed every number and
  read or recomputed it from its primary source: run artifacts (`runs/`), certificates, `bench/`, the budget ledger and
  cassettes, `docs/gates.md` for the gate's own measurements, git. A session report counts only when nothing else holds
  the number (marked "✓ report").
- **Refute.** For each chunk, a skeptic re-derived every flagged number independently and either refuted the flag or
  confirmed it with the correct value and the replacement wording; a cross-document check compared the same quantity
  across documents and covered every line with a digit the chunks missed.
- **Fix and re-check.** S9 fixed what was confirmed (the README, the storyboard, the A/B data in `runs/g3/ab.json` and
  the site's copy in `src/site/` and `src/report/`, each site fix with a regression test), then three more agents
  checked every changed line and every number S9 added (its own timings, the S3 range certificate, the video's script,
  shots and cards), and a last skeptic tried to break the script; what they found is fixed too.
- **S9's own runs** are the source for S9's timings and digests: a fresh clone of `003e331`, an empty npm cache,
  nothing else running (`npm ci` 16 s; `npx ac demo --replay` 11 m 08 s; `--env --oracles` 20 m 32 s, the four digests
  identical to the recording; the suite 1,375 passed), and the site built twice, byte-identical.

Status: **✓** the primary source agrees (a correct rounding counts); **✓ report** only a session report or the gate
report holds it, and it agrees; **model's words** a number inside a model's own text (the critic's review, a
narration), quoted and labeled as the model's on the page, with the record next to it. Lines are the line in the file,
or in a text dump of the built page for the site.
